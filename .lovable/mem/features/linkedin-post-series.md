# LinkedIn poszt-sorozat (Kylo történetív)

Személyes hangvételű, sorozatos történetmesélés; a termék csak burkoltan
(„hátsó ajtó”), a „kit” említése konzisztensen visszatér.

1. **Személyes küzdelem** — gépelés helyett szóbeli gondolkodás, hangalapú
   workflow. (Kiment.)
2. **Felismerés / memória** — „Hogyan tanítottam meg az AI-t emlékezni?”:
   a szabályzatok nem a modell memóriájában, hanem strukturált archívumban;
   3 havonta frissülő nyelvvizsga-szabályzatok, évente az érettségi modulok;
   „amőba”-ajánlat: hiányzó vizsga 2 héten belül beépítve. (Csütörtökre időzítve.)
3. **Kylo Logic** — a rendszer mögötti logika / működés.
4. **Teljes szortiment** — ITT a nyitány: **érveléstechnika, vitaszimulátor,
   kritikai gondolkodás**. Ezt szándékosan kivettük a 2. posztból, hogy a 4.
   poszt erős nyitánya legyen. Ide jön a teljes képességprofil (nyelvvizsgák,
   soronkénti magyarázat, vizsgáztatói személyiségek, szakmai vizsgák).

Szabály: egy poszt max ~230-280 szó; a lényeg az első 3 bekezdésben.
